# HortaMap - Rede contra a Fome 🌱

Projeto desenvolvido para o primeiro ano da Graduação de Engenharia de Software da Fiap. O programa tem como objetivo mapear hortas urbanas, tanto comunitárias quanto privadas com preço social.

## 🚀 Funcionalidades
- Cadastro de hortas comunitárias e privadas com preço social
- Localização das hortas dentro de um mapa
- Informações sobre cultivo
- Reservas de alimentos

## 🛠️ Tecnologias
- JavaScript
- HTML
- CSS
- Bootstrap
- React
